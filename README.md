# The Chromatin Game

> **Build the fold. Match the map.**

An interactive Python game about chromatin folding: you're handed a Hi-C
contact map (a heatmap of how often two genomic loci touch in space) and
have to place loops and paint compartments on a live polymer simulation
until its own contact map matches the target. It's the real inverse
problem Hi-C researchers face, turned into a puzzle.

```bash
pip install -r requirements.txt
python main.py
```

Requires Python 3.10+, `pygame-ce`, `numpy`, `scipy`. The 3D renderer, the
Hi-C analysis pipeline, and the colourmaps are all written from scratch.

---

## The physics

A chain of N beads under overdamped Langevin dynamics (a marble in honey,
not free flight). The force field has six terms: backbone bonds, bending
stiffness, excluded volume (soft, crossable), loop bonds (a cohesin ring
pulling two anchors together into a TAD), block-copolymer attraction
(drives the A/B compartment checkerboard), and soft confinement. See
`chromatin/physics.py` for the equations, or open the in-game manual (H).

## Scoring

`chromatin/analysis.py` runs a miniature real Hi-C pipeline: O/E
normalisation → correlation matrix → E1 (compartments). Your score combines
SCC (stratum-adjusted correlation, the headline number), E1 correlation,
checkerboard correlation, and anchor F1 (precision/recall of loop
placement). Your map is always an ensemble average over simulation time —
press Enter to measure and lock in a score.

## Gameplay

- **Single player** — you control both loops and compartments.
- **Two-player versus** — one player per feature, scored independently on
  the same polymer.
- **Hard mode** — the target's loop anchors and E1 track are hidden.
- **Chromatin MiNI-Lab** — a free-play sandbox with live sliders for every
  force-field parameter and a live structural-metrics panel.

## Controls

| Key | Effect |
|---|---|
| **L / C** | loops mode / compartments mode |
| click a map cell (i,j) | tie or untie that loop |
| click/drag the colour ribbon | paint A/B compartments |
| click bead i then j in 3D | tie a loop (alternative) |
| drag empty space / wheel | orbit / zoom the 3D view |
| **Enter** | measure ensemble, lock in a score |
| **A** | structural analysis panel |
| V | cycle map view | **T** | cycle bead colour mode | **G** | cycle 3D shape |
| Space · F · R | pause · fast-forward · reset camera |
| H / F1 | in-game manual | **M** | music | N · +/- | next track · volume |

## Music

The soundtrack is original piano music composed and played by
**Sebastian Korsak** (BlackPianoCat) — see `music/`. Press **M** to start
it; the game runs fine with no music files and no audio device.

## Appearance

Settings has a theme picker (Daylight, Paper, Midnight, Carbon, Nebula —
3 dark, 2 light), switchable live. UI text is bundled Quicksand; numbers
and aligned data use a monospace font.

## Code layout

```
chromatin/
  physics.py / physics_jax.py   force field (JAX-fused stepping, optional)
  analysis.py                   O/E, correlation matrix, E1, SCC, F1, scoring
  levels.py                     level definitions, cached targets
  render3d.py / render3d_gpu.py software / Panda3D 3D renderer
  beadcolor.py / chainshape.py  bead colour modes & backbone shapes (shared)
  widgets.py / theme.py         heatmaps, metric table, palettes, fonts
  app.py / draw.py / interact.py / session.py   game loop, drawing, input, state
  metrics.py / analysis_panel.py                live structural metrics panel
  manual_panel.py / manual_content.py           in-game manual
```

Targets are generated by the game's own simulator on a hidden ground
truth, cached in `.cache/` after first load. Solo records land in
`records.json`.

## Resetting progress

`rm -rf .cache records.json settings.json` from the project root wipes
cached targets, personal records, and settings back to defaults — all
three are quietly recreated as needed.

## Dependencies

```
pygame-ce >= 2.4    # rendering and audio
numpy    >= 1.24    # all numerics
scipy    >= 1.11    # KD-tree neighbour lists for large N
matplotlib >= 3.7   # equation rendering in the manual
Pillow   >= 9.0      # tight-crop of rendered equations
numba    >= 0.58    # optional: multi-core force kernel
jax / jaxlib >= 0.4  # optional: JIT-fused CPU physics stepping
panda3d  >= 1.10     # optional: GPU-accelerated 3D view
```

JAX, numba and Panda3D are all optional — if any fails to import or
initialise, the game falls back to the plain-numpy physics loop and/or
the software 3D renderer automatically.
